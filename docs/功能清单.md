# NLapt 功能与界面清单

对应产品 **0.2.1**。依据当前代码与界面实现整理（不是早期需求书里尚未做成的规划项）。主界面骨架对齐 `nlapt-prototype/`。当前版本说明见 [`更新日志.md`](更新日志.md)。

**NLapt**（Natural Language Annotation Processing Tools）是面向 **自然语言标注（caption）** 的桌面编辑器。典型用途：LoRA / 图像生成模型训练集制作、图文数据集清洗、任何「图片 + 同名 `.txt`」的批量编辑。

- **平台**：Windows 优先，跨平台（Python 3.11+ / PySide6）
- **数据格式**：kohya 约定——每张图配同名 `.txt`；danbooru 标签与自然语言可混排；递归扫描子文件夹（如 `10_conceptname`）
- **支持图片**：`.jpg` / `.jpeg` / `.png` / `.webp` / `.bmp`
- **界面语言**：中文
- **设计底线**：批量操作可预览、自动快照、可回滚；标注只在显式「保存」时写入磁盘

---

## 1. 能做什么（按工作流）

### 1.1 打开与浏览数据集

- 打开一个文件夹作为数据集根目录（左侧图标轨 **打开**，或文件栏小图标）
- **导出** 把当前数据集的图片 + 已有同名 txt 打成 zip（排除 `.backups` / `.nlapt`）；有未保存时先确认是否全部保存再打包
- 递归扫描图片，按「同目录、同主文件名」配对 `.txt`（扩展名不区分大小写）
- 只有图、没有 txt 的视为 **未标注**（空内容），首次保存时自动创建同名 txt
- 只有 txt、没有图的孤儿文件默认不展示
- 下次启动 **自动重开上次目录**
- **刷新** 重新扫描当前目录
- 非 UTF-8 编码（如 GBK）打开时提示，保存后转为 **UTF-8 无 BOM**
- 未保存草稿写入会话文件（`.nlapt/`），崩溃后重开自动恢复

### 1.2 逐张编辑标注

三种视图看同一份文本，切换即时同步：

| 模式 | 做什么 |
|---|---|
| **胶囊** | 按逗号切成标签胶囊：点选 → 再点编辑、拖拽排序、`+ 标签` 新增、× 删除 |
| **分句** | 同样按逗号分段，每段一行：拖动手柄排序、编号徽章、多行内联编辑、`+ 添加分段` |
| **文本** | 整篇自由编辑；拖选文字后可 **替换 / 删除 / 润色**（润色 = 整理空格与逗号，不是 LLM） |

胶囊 / 分句选中一段后，正上方弹出 **悬浮工具栏**：

- **分段**：在光标处拆成两段
- **插入**：在此段后插入新片段
- **翻译 / 重译**：翻译这一段（中英互转 / 换一种译法），先预览再替换
- **删除**：删掉这一段

### 1.3 整篇标注工作区（当前文件）

编辑器页签右侧的 **标注工作区**：

- **翻译 ▾**：整篇译成 中文 / English / 日本語（走设置里的翻译服务）
- **LLM 推理**：用在线视觉模型重新看图，生成全新标注
- **本地推理**：用设置里选好的本地模型看图打标
- **删除**：清空当前标注（可 Ctrl+Z 撤销）
- **译文**：把当前标注译成中文，常驻显示在编辑器底部（不替换原文）

翻译 / 推理结果先弹出浮动预览卡，点 **替换** 才写入编辑器（不会静默覆盖）。「译文」只对照、不覆盖。

### 1.4 多选对比编辑

- **Shift+点击**：范围多选
- **Alt+点击**：取消选择
- 左栏 **全选 / 已选 n / 清除**；每个文件夹标题有三态复选框；顶部 **ALL** 行全选
- 最多 **4 张** 并排预览与编辑；超过 4 张时提示「仅显示前 4 张」
- 多选时切图锁定在选中集内

### 1.5 批量改字（轨上「修改工具」浮层）

作用域统一为 **当前 / 文件夹 n / 选中 n / 全部 N**（「文件夹」含当前文件所在目录及其嵌套子文件夹）：

- **查找替换**：实时统计「匹配 x 处 · y 个文件」；可区分大小写、整词匹配；替换为空即删除；执行前自动快照
- **前缀 / 后缀**：加到开头或结尾；「作为独立标签」自动加逗号、已存在则跳过（防触发词重复）
- **翻译对照**：原文 / 译文并排；分段或整段对照；一键「中文全部转为英文」
- **历史记录**：当前文件每一步带标签的快照，可回退到任意一步，可清空历史（保留当前）

### 1.6 批量推标（看图生成 / 覆盖标注）

在左栏右键：

| 右键目标 | 菜单项 |
|---|---|
| 单张图片 | 用 LLM / 本地模型推理 **这张图片**；**CHA标注这张图片**；**多对比推标这张图片** |
| 多选中的一张 | 推理 **已选**、推理 **全部**；**CHA标注已选 / 全部**；**多对比推标已选 / 全部** |
| 子文件夹标题 | 推理 **此文件夹**、**此文件夹未标注**、**全部**；对应的 CHA标注项与多对比推标项 |
| ALL 行 / 根目录 | 推理 **全部**、**全部未标注**；对应的 CHA标注项与多对比推标项 |
| 推标进行中 | **取消当前推标**（替换整个菜单） |

**CHA标注**（完整名组合分层推标 / Combined Hierarchical Annotation）：向导里填角色名 / 作品名、点参考图、生成三套人物卡（可编辑英文，中文仅对照；每套旁标注实际调用模型）。人物卡默认先写发色、发型、眼睛，再写纹身等体表，最后写完整服装（可见纹身、叠穿、绑带、印花不得省略）。确认后整批写成「人物卡 + 空行 + 画面段」。画面段那次推理同时核对服装：与人物卡里的官方服装不同时，保留固定外貌（发色 / 眼睛 / 纹身等）、按图改写服装段；相同则人物卡原样保留（每张图仍只调用一次）。确认页分别显示「固定外貌」与「官方服装」，未识别到服装段会提示。下次只回填角色名和作品名，**不会**把上一套人物卡填进候选 1。Florence-2 不支持自定义提示词，CHA标注请改用 LLM。中文对照走设置里的翻译服务（含 DeepLX / 本地 Hy-MT2）。对照写进卡片后窗口高度不变，在候选页内滚动，不会被顶出屏幕。接口与模型在设置 ▸ CHA标注：默认同步 LLM 设置，也可单独填 API；三个方案和整批画面段可从模型池按供应商分组选模型，可跨 API。

**多对比推标**（工具弹层 ▸ 标注工具）：与 LLM 推标同一套提示词，但把范围内每张图同时交给设置 ▸ 多对比推标里勾选的多个模型（可来自不同 API，各自并发限速）。结果流入对比窗口：左侧图片列表，右侧缩略图 + 每个模型一张卡（模型名、可编辑标注、失败原因）。逐张点选要采用的卡，或「全部采用 某模型」；「写入已选 (n)」才把选中的标注写入 txt——走与 LLM 推标相同的快照 / 操作日志 / 历史路径，可整批回滚；未选的图片不动。推理中可「停止推理」，已返回的结果仍可选择写入。

执行前确认（会覆盖现有标注、先自动备份）。弹出 **推标进度** 窗口：进度条、张数、速度（张/分）、已用时间、预计剩余；可 **后台运行** 或 **取消推标**。取消后重开从断点续跑，已完成的不重推。

本地批量全程复用同一 llama-server；推理拉起的服务空闲 **30 秒** 才卸载（用户手动启动的永不自动停）。

### 1.7 接在线 LLM / 翻译 API

- 接口：**OpenAI / Anthropic / Ollama** 兼容
- **多个 API 档案**同时保存（新增 / 删除 / 重命名），每个档案有自己的模型开关列表；勾选的模型汇成一个**模型池**
- **当前文本模型**（翻译 / 改写）与**当前视觉模型**（推标 / CHA）分别从模型池里选，可来自不同 API；选同一个多模态模型即等于旧的「统一」模式
- **获取模型**：拉取该 API 的模型列表并入开关列表（默认不勾选），疑似多模态会打标；接口不支持列表时可手动输入模型 ID
- **快速切换**：左侧「工具」弹层顶部显示当前文本 / 视觉模型，点开即可在模型池里切换（类似 pi 的 Ctrl+P），批量进行中禁用
- **测试连接**：用该档案第一个已勾选模型测通并显示耗时（思考型模型不会因为空回复直接失败）
- 翻译服务可改走 **大模型**，或 **Google（免费）/ 百度 / DeepL / DeepLX（免费社区或自建）/ 本地 Hy-MT2 / 自定义 OpenAI 兼容**
- LLM / 翻译 / CHA 的接口配置（类型、地址、密钥、模型开关、当前模型）统一写在 **文档/NLapt/api.json**（v2；不进 AppData）。第一次启动会把旧的 `config.json` 档案、`translate.json` 密钥、`translate_api.json`、`cha_api.json` 迁过去并清掉残留；旧版单档案配置读入时自动升级：原文本 / 视觉模型被勾选并设为当前模型
- **备选顺序**：首选失败后按名单继续试（例如 DeepLX → Google → 百度 → 本地模型）；未配置的自动跳过。设置里可上移 / 下移 / 添加 / 移除，或「填入推荐」
- 社区 DeepLX 限流（HTTP 429 / 418）会自动退避重试；仍失败则走备选。全部失败时显示最后一个服务的错误（DeepLX 忙时是「过于频繁…」，不会出现 teapot）
- 本地 Hy-MT2：设置里选档位（快速 1.8B 2bit / 均衡 1.8B Q4 / 高质量 7B Q4），「管理模型」下载到 `models/mt/<档位>/`，走独立 llama-server，不占用打标模型
- 图片推理提示词：模板新建 / 保存 / 删除 / 导出；在线与本地默认共用，也可给本地单独一套
- 并发数可调；网络与磁盘操作全部异步，界面不卡

### 1.8 本地推理（离线打标 / 当翻译模型）

设置 ▸ **本地推理**：

- 内置模型目录（大系列 ▸ 小系列 ▸ 量化档），标注体积、热度、「能否运行」五级评级
- 应用内下载：断点续传、进度条、可取消、SHA256 校验；视觉模型自动带 mmproj
- 下载目录默认在程序旁 `models/`，可改；可加多个 **复用目录**（别的工具下过的同款 GGUF 直接用）
- 首次使用自动下载固定版本的官方 **llama-server**（Windows 用 Vulkan，通吃 NVIDIA / AMD / Intel；没有 Vulkan 则 CPU）
- 可配：上下文长度、GPU 层数（-1=自动）、线程、并发请求数、端口
- **设为当前模型**：把该模型登记为 `local` 档案并设为当前文本模型（有视觉能力时也设为当前视觉模型），翻译 / 重译 / 批量 AI 立刻切到本地，无需 API Key；纯文本模型不改动已选的视觉模型
- Florence-2 系列免 llama-server，进程内 ONNX 推理；用 **指令模式** 而不是自由提示词
- Florence 可挂 **LoRA**（内置可下载，或自选 `.safetensors`）
- JoyCaption / ToriiGate 有官方 **提示词预设**
- 本地 **Hy-MT2 翻译模型**不在本页，在「翻译服务」里选档位并「管理模型」

### 1.9 数据安全

- 标注 **只在**「保存 / 全部保存 / Ctrl+S / Ctrl+Shift+S」时写入 `.txt`
- 未保存用黄点标在列表、预览、编辑块；结果用 Toast 提示
- 任何批量操作前把全部 txt 打成 zip 放进 `.backups/`（默认留 20 份）
- 原子写入（临时文件 + rename），中断不损坏文件
- 崩溃恢复：会话文件在 `.nlapt/`
- 推标被安全策略拦截时，拒绝话术 **不会** 写进数据集（该张失败、保留原文）
- 接口密钥统一在 **文档/NLapt/api.json**，不进数据集目录，也不进 `%APPDATA%/NLapt/config.json`

### 1.10 外观

- 无边框自绘窗口；拖轨空白或预览信息栏移动；边缘拖拽缩放；双击信息栏最大化
- 五套主题：**明亮 / 雾灰 / 石墨 / 深邃 / 墨黑**（轨上主题钮弹出五套 + 色彩设置）
- **色彩设置**：预设主题色或任意取色，即时生效
- 窗口与子窗口居中、淡入淡出
- 不再常驻状态栏：Toast + 列表黄点 + 推标进度窗

## 2. 主界面总体布局

无边框窗口，最小约 **1360 × 760**。从左到右：

```
┌ 44px 轨 ┬ 260px 文件栏 ┬ 预览 + 编辑 ─────────────────────────┐
│ Logo    │ 搜索 / 列表中图大图 / 已选 n                        │
│ 打开    │ 数据集名（树根）+ 刷新                              │
│ 保存    │ ALL □ + 文件夹三态框 + 缩略图 + 黄点               │
│ 全部保存│                                                     │ 46px 信息栏
│ 导出    │                                                     │ 文件名 PNG 尺寸 大小 修改于 ─ □ ×
│ 撤销    │                                                     │ 预览 / 最多 4 张对比
│ 重做    │                                                     │ 8px 拖条
│ 修改工具│                                                     │ 胶囊 | 分句 | 文本   翻译 LLM 本地 删除
│ 主题    │                                                     │ 编辑器
│ 设置    │                                                     │
└─────────┴──────────────┴──────────────────────────────────────┘
         └ 点「修改工具」→ 右侧 340px 浮层：查找替换 / 前缀后缀 / 翻译对照 / 历史 ┘
```

两栏是一条水平分隔条（默认左 260、中 760，文件栏最小 200）。中间再竖切：上预览、下编辑，中间 8px 拖条调编辑区高度（约 170–620px，默认 330）。栏宽与编辑区高度会记住。旧的三栏宽度档只保留左侧数字。

## 4. 左栏：文件列表

### 4.1 头部

- 文件夹图标、**数据集名**、等宽 **路径**（过长省略，悬停看全路径）
- **刷新**、**打开文件夹**

### 4.2 搜索与视图

- 搜索框：「搜索文件名 / 标签…」（不区分大小写，文件名或 caption 包含即命中）
- 无匹配时：「没有匹配的文件」
- 分段按钮：**详细列表 / 中图网格 / 大图网格**

### 4.3 选择行

- **全选** 复选框
- **已选 n**
- **清除**

### 4.4 ALL 行 + 文件夹分组

- 永久第一行：**ALL** + 总数 + 三态复选框（全选/部分/全不选）
- 其下按相对路径分组；根目录下的文件归入 **根目录**
- 每组：折叠箭头（动画）、文件夹名、**n 张**（搜索时 `k/n 张`）、三态复选框
- 文件夹开合状态会记住

**列表视图** 每行约 62px：复选框、34×44 缩略图、文件名、标注预览（前几段）、段数（如 `6段`）、未保存黄点。当前项强调色描边。

**中图 / 大图网格**：缩略图卡片，底部渐变条上是文件名和段数；左上复选框；未保存黄点；当前项软光晕。大图最小边约 150px，中图默认最小 96px。

缩略图后台解码，内存 LRU + 磁盘缓存（`%APPDATA%/NLapt/thumbs`，按源文件 mtime+size 键控）。刷新只清内存，磁盘缓存保留，二次打开更快。

### 4.5 页脚

- `n 张图片 · 已选 m · 未保存 k`
- 有未保存时再显示黄点 + 「未保存 k」

### 4.6 右键推标（按点击目标出菜单）

见 [1.6](#16-批量推标看图生成--覆盖标注)。普通推标与 **CHA标注** 按同一套目标出菜单。推标前确认文案会说明：覆盖现有内容、先自动备份、可在历史记录整批回滚。

## 5. 中栏上：图片预览

### 5.1 信息栏（46px）

从左到右：

- 等宽 **文件名**
- 格式胶囊（`PNG`）+ `宽 × 高` / 大小 / `修改于 yyyy-mm-dd`
- **未保存** 胶囊（脏时才出现）
- 多选时：**对比 · 已选 n · 切换锁定在选中集**
- **上一张 / 下一张**（Alt+↑ / Alt+↓），中间位置 `i / n`
- 窗控 ─ □ ×（关闭悬停为 Windows 红）

### 5.2 单图预览

- 默认 **适应** 窗口
- 滚轮缩放 **40%–260%**，每格 20%
- 双击在「适应」与 **100%** 之间切换
- 浮层缩放条：`−` 百分比/`适应` `+` **适应**

## 6. 中栏下：标注编辑器

### 6.1 页签行

左：**胶囊 | 分句 | 文本**（当前页签强调色）

右：**标注工作区**——翻译 ▾、LLM 推理、本地推理、删除、译文

模式提示（换页签时）：

- 胶囊：点击选中 · 再次点击编辑 · 拖动排序 · 悬浮工具栏 · × 删除 · 按英文逗号分段
- 分句：按英文逗号分段 · 拖动手柄排序 · 点击选中 · 再次点击编辑
- 文本：拖选后替换 / 删除 / 润色 · 失焦记一条历史

### 6.2 编辑块

- 单选：一块，占满
- 多选：最多 4 块，点块头切「当前」
- 每块头：等宽文件名、未保存点、**编辑中** 徽章、`n 字符 · m 段`

### 6.3 胶囊模式

- 按半角/全角逗号切段，每段一枚胶囊
- 第一次点击 = 选中（强调高亮），第二次 = 行内编辑
- 拖拽排序，释放处有强调色指示条
- 末尾常驻 **+ 标签**
- 空状态：「暂无内容,点击「+ 标签」添加」
- 编辑时若输入逗号会拆成多枚；空提交等于删这段
- 写回用 `", "` 连接

### 6.4 分句模式

- 分段规则与胶囊相同（逗号，不是句号）
- 每行：六点拖动手柄、两位编号、文本、删除
- 再点进入自适应高度的多行编辑
- 底部 **+ 添加分段**

### 6.5 文本模式

- 多行文本框，占位「在此输入标注文本…」
- 边打边改内存，**失焦** 才记一条「自由编辑」历史
- 选中文字后上方操作条：`已选中 n 字符` + 替换为… + **替换 / 删除 / 润色**
- 删除会收掉多余逗号；润色按逗号 trim 再拼回去

### 6.6 悬浮工具栏与预览卡

- 锚在选中/正在编的那段 **正上方**（太靠顶就翻到下方），随滚动走
- 没有锚点时退回顶栏中央
- 按钮按 **按下** 就触发（避免行内编辑先失焦）
- 翻译/推理结果用同一张 **TranslationPreview**：标题、可滚动正文、**替换 / 关闭**
- 长文不会把按钮顶出窗口

### 6.7 标注工作区细节

|---|---|

## 7. 右栏：修改工具

标题 **修改工具**，一行显示「n 张 · 已选 m」和关闭钮；悬停看副标题「对当前文件或批量范围应用修改」。四个可折叠卡片，开合与高度会记住。

共享 **应用范围**：当前 / 文件夹 n / 选中 n / 全部 N。

### 7.1 查找替换（默认展开）

- 查找：如 `long hair`
- 替换为：留空则删除
- **Aa 区分大小写**、**W 整词**（`hair` 不会打到 `hairband`）
- 实时：`匹配 {total} 处 · {files} 个文件` / 无匹配 / 请先输入
- **全部替换** → 快照 → 批量引擎 → 结果 toast

匹配是整篇 substring，不限于逗号段。

### 7.2 前缀 / 后缀（默认收起）

- 输入：如 `aoba, masterpiece`
- **加到开头 | 加到结尾**
- **作为独立标签 (自动加逗号)**（默认开：已有则跳过）
- **应用** → 快照后批量写入

### 7.3 翻译对照（默认收起）

未配翻译 API 时：引导文案 + **打开设置**。

配好之后：

- **对照方式：分段 | 整段**
  - 分段：一行一段，⇄ 只换这一段；长句被逗号切开时译文容易碎
  - 整段：整篇一行，译文更顺，⇄ 换整篇
- 每行：原文、译文（翻译中…）、⇄ **翻译替换**
- **中文全部转为英文**：按当前对照方式，对范围内含中文的文件批量翻译并写回
- 译文按内容缓存，相同文本只请求一次；编辑后约 400ms 再请求
- 批量进行中不能改对照方式
- 走社区 DeepLX 时可能限流：会自动重试，仍失败则显示「过于频繁」而不是英文报错；自建 DeepLX 或本地 Hy-MT2 更稳

### 7.4 历史记录（默认展开）

针对 **当前文件**：

- 每条：时间、操作标签（如 自由编辑 / 翻译替换 / 推理(本地)）、字符数、摘要
- 当前那条标 **当前**（强调底）
- 其它条有 **回退**（跳到那一版，不删后面的记录）
- **清空历史**：只留当前状态

这是界面级逐步历史，和批量前的 zip 快照不是同一套。

### 9.4 本地推理（横构图，最小约 840×520）

**顶**：本机硬件一行（CPU 核数、内存、NVIDIA 显存）+ **重新检测**

**左：目录树**（列：模型 / 体积 / 热度 / 能否运行）

大系列 → 小系列 → 量化档。只有一个家族的系列不再套一层；只有一个量化档的家族合成一行。

| 评级 | 含义 |
|---|---|
| 轻松运行 | 显存余量足，全在显卡里 |
| 流畅运行 | 能全进显存 |
| 可以运行 | 要借内存，或没独显 |
| 勉强能跑 | 余量很小，可能不稳 |
| 跑不动 | 超出显存+内存（会写还差多少） |
| 未检测 | 硬件没测到 |

评级跟右侧 **上下文长度 × 并发** 一起算，明细含：权重 / 视觉组件 / 上下文 / 开销，以及显存、内存预算。★ 推荐标在推荐量化档上。

**右：操作**

- 评级说明 + 占用明细
- **下载模型**（已就绪可重新校验）/ **取消下载** + 进度
- **打开模型页**（浏览器）
- **启动本地服务 / 停止服务**（Florence 无需启动；只能拿来停已经在跑的 llama）
- **设为当前模型**（Florence 禁用：它不能当翻译/重写后端）

**表单（随模型显隐）**

| 项 | 何时出现 | 作用 |
|---|---|---|
| 指令模式 | Florence | 标签 / 各级标题 / 构图分析 / JSON 等 |
| LoRA | Florence | 不使用 / 内置可下载 / 自选 safetensors；添加、移除、下载 |
| 提示词预设 | JoyCaption、ToriiGate | 官方指令；末项「自定义(使用推理提示词)」 |
| 下载目录 | 始终 | 默认程序旁 `models/` |
| 复用目录 | 始终 | 在这些目录里找已有 GGUF，找到就不重下 |
| llama-server | GGUF | 默认自动（内置 llama.cpp，首次用再下） |
| 上下文长度 | GGUF | 每槽位；实际 `-c` = 上下文 × 并发 |
| GPU 层数 | GGUF | -1 = 自动（按显存和层数算） |
| 线程数 | GGUF | 0 = 自动 |
| 并发请求数 | GGUF | 同时几路请求 |
| 端口 | GGUF | 默认本机 `127.0.0.1:{port}/v1` |

下载关对话框再开，进度会接上。一次只下一个任务。

| 快捷键 | 功能 |
|---|---|
| `Ctrl+S` | 保存当前 |
| `Ctrl+Shift+S` | 全部保存 |
| `Ctrl+Z` | 撤销（焦点在输入框时先撤销输入） |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做（焦点在输入框时先重做输入） |
| `Ctrl+Shift+C` | 复制当前标注 |
| `Esc` | 收起修改工具浮层 |
| `Alt+↑` / `Alt+↓` | 上一张 / 下一张 |
| `Shift+点击` | 范围多选 |
| `Alt+点击` | 取消选择 |

需求书里的 `1/2/3` 切模式、`←/→`、`Ctrl+Enter` 确认、`A/X` 接受拒绝、`Ctrl+F`、`Ctrl+,` **界面尚未做成全局快捷键**。

## 13. 配置与数据落在哪

| 位置 | 内容 |
|---|---|

源码目录跑时，默认模型目录是仓库里的 `models/`（已 gitignore）。

## 15. 和早期需求书的差别（避免当成已有功能）

`NLapt.md` 里写过、**当前界面还没有** 的：

- 左栏状态筛选：未标注 / 草稿 / 待审核 / 已确认
- 「标为已确认」和 Ctrl+Enter 跳下一张未确认
- CLIP token 估算与 77 截断警示
- 右栏 **AI 润色 / 重写**（扩写、精简、试跑、视觉开关）
- 预览区与编辑器之间的 **Diff 审核条**（接受 / 拒绝 / 编辑后接受，A/X）
- 查找替换的正则、逐个替换、执行前逐文件预览勾选
- 触发词预设库
- 快照管理窗口（「从 zip 恢复」没有单独入口；批量回滚走操作日志，逐步回退走右栏历史）
- 搜索前加 `-` 表示「不含」
- 按修改时间 / token 数排序
- 左右栏一键折叠
- 费用估算

核心库里部分能力（操作日志回滚、批量引擎、审核状态）已经有，但 **没有完整做成上述界面**。
