# NLapt 前端设计清单

对应产品 **0.2.0**。依据当前 PySide6 实现与 `nlapt_gui/theme/` 令牌整理。骨架对齐 `nlapt-prototype/`（静态视觉稿，不进运行时）。

设计源自 CaptionForge 原型（`NLapt-head/.../标注编辑器 CaptionForge.dc.html`），落地为无边框桌面窗，不是浏览器页。本文只讲**看起来什么样、怎么排布、用什么组件、动效怎么做**；功能见 [功能清单.md](功能清单.md)。

---

## 1. 设计原则

| 原则 | 落地 |
|---|---|
| **轨 + 两栏工作台** | 左 44px 图标轨、文件栏、预览+编辑。修改工具是轨上抽出的右侧浮层。中间永远最大。 |
| **令牌驱动，零硬编码色** | 所有颜色来自 `ThemeTokens`，经全局 QSS 或令牌查找。控件模块禁止写 `#RRGGBB`（测试会 grep）。 |
| **中文界面 + 行业英文** | 用户文案中文，术语可混排（胶囊、token、LoRA）。代码/注释英文。文案是模块顶常量，不写在控件字面量里。 |
| **先看再改** | 翻译 / 推理结果用浮动预览卡，点「替换」才写入。危险操作二次确认。 |
| **键盘流** | 切图、保存、撤销 / 重做、范围选都有快捷键；状态靠 Toast 与列表黄点，不再常驻底栏。 |
| **不闪、不崩** | 子窗居中淡入淡出。顶层窗口、预览区、活着的面板 **禁止** `QGraphicsOpacityEffect`（原生缩放会硬崩）。顶层只用 `windowOpacity`。 |
| **测试可关动画** | 所有动效走 `nlapt_gui.anim`；关掉时直接跳到终态，不依赖真实等待。 |

视觉气质：**扁平、克制、偏编辑器**。浅色偏纸/雾，深色偏石墨/墨。强调色默认青绿，面积小（当前项、主按钮、选中胶囊），不用渐变墙、不用彩虹状态色。

## 2. 窗口骨架

无边框自绘窗（`Qt.FramelessWindowHint`）。系统缩放用 `startSystemResize`，**不用** `WM_NCHITTEST`（HiDPI 会吞点击）。

| 度量 | 值 |
|---|---|
| 最小窗口 | **1360 × 760** |
| 左侧图标轨 | 宽 **44px** |
| 文件栏默认 / 最小 | 260 / 200 |
| 中栏默认 / 最小 | 760 / 360 |
| 修改工具浮层 | 宽 **340px**，默认隐，从右侧盖住中栏 |
| 两栏分隔条 | 宽 **4px** |
| 预览信息栏 | 高 **46px**（拖窗 + ─ □ ×） |
| 预览↔编辑分隔条 | 高 **8px**，中间 44×3 握把 |
| 编辑区高度 | 170–620，默认 **330** |
| 边缘可拖缩放热区 | 8px |

```
┌ 44px 轨 ┬ 260px 文件 ┬ 预览 + 编辑 ──────────┐
│ 图标    │ 搜索/视图  │ 46px 信息栏 + 窗控    │
│ 打开    │ 树 + 列表  │ 预览 + 缩放          │
│ 保存…   │            │ 8px 拖条             │
│ 导出    │            │ 编辑器               │
│ 撤销/重做│           │                      │
│ 修改工具│            │                      │
│ 主题/设置│           │                      │
└─────────┴────────────┴──────────────────────┘
         └ 点「修改工具」→ 右侧 340px 浮层 ToolsPanel ┘
```

- 两栏 `QSplitter` 宽度写入 `body_splitter.json`（旧三栏档只保留左侧宽度）。
- 编辑区高度写入 `UISettings.editor_h`。
- 小屏还原最大化：窗口降到可用区域的 **86%** 再居中，避免「还原等于全屏」。

层级（从底到顶）：

1. 窗体 `bg`
2. 轨 / 文件栏 / 信息栏 `panel`
3. 卡片 / 输入 `surface`，浅凹槽 `surface2`
4. 悬浮工具栏、预览卡、Toast（叠在内容上，不占布局）
5. 模态设置 / 色彩 / 确认框（居中 + `windowOpacity`）

## 3. 颜色令牌

一套主题 17 个色。换肤 = 整表替换 + 可选覆盖 `accent`。

| 令牌 | 用途 |
|---|---|
| `bg` | 窗口底、编辑框浅底 |
| `panel` | 轨、文件栏、预览信息栏、工具浮层 |
| `surface` | 卡片、输入、菜单、胶囊默认 |
| `surface2` | hover 底、分段条槽、pill 中性底 |
| `bd` / `bd2` | 细边 / 更明显的边（hover、分割） |
| `text` / `text2` / `text3` | 主文 / 次文 / 弱文（提示、时钟、禁用） |
| `accent` / `accent2` | 强调、主按钮；`accent2` 是更深/更亮的 hover |
| `onaccent` | 铺在强调色上的字（浅色主题白，深色近黑绿） |
| `ok` / `warn` / `danger` | 成功 / 未保存黄 / 删除与错误 |
| `scroll` | 滚动条滑块 |

### 3.2 派生色（禁止手写，用 `mix`）

对应原型 CSS `color-mix(in srgb, …)`，在 sRGB 里按百分比混。

| 名字 | 算法 | 用在 |
|---|---|---|
| `accent-soft` | 14% accent + 86% bg | 选中胶囊底、toggle 开、下拉选中项 |
| `accent2`（自定义强调时） | 82% accent + 18% text | hover 强调 |
| selection | 28% accent + 72% bg | 文本选区 |
| accent25 / accent40 | 25% / 40% accent + bg | 按下、强调软框边 |
| danger-soft | 14% danger + bg | 危险幽灵按钮 hover |
| 滚动条 hover / pressed | scroll↔text / accent↔scroll | 滑块交互 |

### 3.3 强调色预设（可自定义）

默认 `#0E9384`。色彩设置里四颗：

| 色 | 感觉 |
|---|---|
| `#0E9384` | 青绿（默认） |
| `#4F63E7` | 靛蓝 |
| `#D9634A` | 陶红 |
| `#B58326` | 琥珀 |

另可系统取色器任意 `#RRGGBB`。改完立刻 `ThemeManager.apply`，写入 `ui_settings.json`。

### 3.4 唯一例外的「系统色」

关窗按钮 hover 用 Windows 红，也做成令牌，不写在控件里：

- `WINDOWS_CLOSE_HOVER` `#E81123`
- `WINDOWS_CLOSE_HOVER_FG` `#FFFFFF`

预览图上的暗角/白字从 **墨黑.bg** 和 **明亮.onaccent** 取，不另开令牌。

「能否运行」五级 **只用文字、不上色**（避免五套主题下手写色，也避免红绿交通灯）。

## 4. 字体

不打包字体，只声明栈：

| 栈 | 字体 | 用在 |
|---|---|---|
| UI | IBM Plex Sans → Segoe UI → 微软雅黑 → PingFang SC | 几乎全部 |
| 等宽 | IBM Plex Mono → Consolas → monospace | 路径、文件名、版本号、时钟、查找框、段数 |

全局正文字号 **13px**（`BASE_FONT_PX`）。层级（实现里实际用到的）：

| 级 | 字号 | 字重 | 用在 |
|---|---|---|---|
| 窗名 | 13 | 700，字距 0.2px | 标题栏「NLapt」 |
| 栏标题 | 13 | 700 | 「修改工具」 |
| 卡片标题 | 12.5 | 600 | 折叠头、菜单项、页签、胶囊正文 |
| 顶栏菜单 | 12.5 | 常规 | 文件/编辑/… |
| 工作区按钮 | 12 | 600 | 翻译 / LLM 推理 / 本地推理 |
| 工具栏按钮 | 11.5 | 600 | 分段、插入、悬浮条 |
| 栏副标题 | 11 | 常规 | 「对当前文件或批量范围…」、状态栏 |
| 胶囊/弱提示 | 10.5 | 600 或常规 | pill、范围标签、缩放条 |
| 微标 | 10 | 常规 | 历史时间、字符数、版本号等宽 |
| 主题箭头 | 9 | 常规 | 主题按钮 ▾ |

等宽再缩小一档：状态栏时钟 **10.5**，标题栏版本 **10**。

## 5. 间距与圆角

### 5.1 4pt 间距尺

| 令牌 | px | 典型 |
|---|---|---|
| `SPACE_XS` | 4 | 紧凑缝 |
| `SPACE_SM` | 8 | Toast 间距、列表行隙、卡片内缝 |
| `SPACE_MD` | 12 | 栏头水平垫、表单缝 |
| `SPACE_LG` | 16 | 栏头左右、标题栏对齐栅格 |

各栏自己还有一套设计稿数字，不必硬套尺，但新控件优先 4 的倍数。

### 5.2 圆角

| 对象 | 半径 |
|---|---|
| 栏内卡片 / `surfaceCard` | **11px** |
| 输入、下拉、分段槽 | **7px** |
| 默认 / ghost 按钮 | **6px** |
| 主按钮、描边按钮、页签、悬浮条按钮 | **7–8px** |
| 胶囊 / pill（设计 999px） | Qt 用 **12px** 近似半高圆 |
| 菜单、下拉列表 | **8px** |
| Toast 胶囊 | **17px** |
| 预览图 | **10px** |
| 多图对比格 | **12px** |
| 网格缩略图 | **9px** |
| 列表行 | **8px** |
| 列表缩略图 | **6px** |
| 复选框 | **4px**（15×15） |
| 网格复选框 | **5px**（17×17） |
| 进度条槽 / 块 | 4 / 3 |
| Logo 徽章 | 24 网格上 6 单位圆角 |

Qt 画不出「半径大于半高」，所以 pill 不用 999。

### 5.3 边框

- 默认分割：**1px** `bd`
- 焦点环：输入 **1.5px** `accent`（Qt 没有 box-shadow，用加粗边代替）
- 当前编辑块：1.5px `highlight`（绑在 `EditorBlock#editorBlock`，避免子胶囊全被当成选中）
- 虚线：**1.5px dashed `bd2`**，只给「+ 标签」
- 分隔线控件：`divider=true`，1px 高，色 `bd`

## 6. 组件目录（QSS 动态属性）

换肤靠属性，不靠每个控件写死色。

### 6.1 按钮 `variant`

| 值 | 样子 | 用在 |
|---|---|---|
| （默认） | 透明，hover `surface2` | 顶栏菜单、小工具按钮 |
| `accent` | 实心强调、白/深字、600 | 保存设置、全部替换、应用、下载 |
| `outline` | `surface` + 1px `bd` | 取消、测试连接、重新检测、浏览 |
| `ghost` | 无边，`text3` | 次要文字按钮 |
| `danger-ghost` | 默认弱，hover 红软底 + `danger` 字 | 关窗感、危险次操作 |

主按钮 padding `5×13`，描边 `4×12`，默认 `4×10`。

### 6.2 分段条 `segBar` + `seg`

槽：`surface2`，半径 7。按钮半径 5，未选透明，选中 `surface` + `accent` 字 + `bd2` 边。

用在：左栏三视图、前缀/后缀位置、翻译对照方式、右栏作用域（当前 / 选中 / 全部）。

### 6.3 开关芯片 `toggleChip` + `chipOn`

小圆角矩形（半径 **6**，不是胶囊）。关：`surface2` + `text3`。开：`accent-soft` 底 + 实线 `accent` 边 + `accent` 字 600。`:checked` 与 `chipOn` 写成同一套，Qt 一翻就变，不等 repolish。

用在：Aa 区分大小写、W 整词、作为独立标签。

### 6.4 胶囊 Chip `chip` / `chipSelected` / `chipActive`

- 默认：`surface` + 1px `bd`，近乎全圆
- hover：边变 `accent`
- 选中：1.5px `accent` + soft 底
- 编辑中：1.5px `accent`，内嵌等宽输入
- 「+ 标签」：虚线框，hover 强调色

第一次点击选中，第二次进入编辑。拖拽源透明度 **0.45**，落点 **3px** 强调色指示条。

### 6.5 Pill 标签 `pill`

| 值 | 样子 |
|---|---|
| `true` | 中性灰底，10.5px |
| `accent` | 实心强调，10px / 700 |
| `accentSoft` | 软强调底 + 强调字 |
| `ok` / `warn` / `danger` | 对应语义软底 |

用在：未保存、编辑中、对比、历史「当前」、图片元信息。

### 6.6 卡片 `surfaceCard`

`surface` + 1px `bd` + 11px 圆角。右栏四块、翻译预览卡。

折叠头高 **40px**，左 15px 描边小图标 + 12.5/600 标题 + 可选等宽后缀 + 12px 旋转chevron（开 0°、关 −90°）。底 **9px** 握把（26×2 横线）可拖高度，内容 120–720px，超出出滚动条。展开/收起是瞬间显隐（防闪），只转动箭头。

### 6.7 输入

- 默认：`surface`、7px 圆、1px `bd`，focus 1.5px `accent`
- `editorField`：`bg` 底、9px 圆（大编辑区）
- `mono`：等宽（路径、查找）
- 下拉箭头是主题色内联 SVG `data:` URI。**`url("…")` 必须加引号**：URI 里的 `;` 不加引号会截断整份样式表。

### 6.8 复选框

15×15，4px 圆。勾选后填满 `accent`。三态（文件夹 / ALL）用 Qt `PartiallyChecked`。网格卡片上的框半透明底（alpha 0.78），保证压在图上也能认。

### 6.9 滚动条

10px 宽，透明轨，滑块 `scroll`、4px 圆、最少 28px。hover / pressed 用派生色。没有上下箭头。

### 6.10 进度条

槽 `surface2` + 1px `bd` + 4px 圆。块 `accent`、3px 圆。推标窗条高 **8px**，百分比写在条外，不画在条上。

### 6.11 菜单

`surface`、8px 圆、5px 内垫。项 12.5px、6px 圆、选中 `surface2`。分隔 1px `bd`。深色主题同步改 Qt 原生 palette，避免系统菜单发白。

### 6.12 Toast

底栏上方居中堆叠，距底 **44px**，间距 **8px**。胶囊 17px 圆，左 **8px** 色点：

| kind | 点色 |
|---|---|
| ok | `ok` |
| warn | `warn` |
| err | `danger` |
| info | `accent` |

内边距 8×16，点与字距 9。**2600ms** 后消失。整层穿透鼠标。

### 6.13 悬浮层

**片段工具栏**：锚在选中段上方 6px，太靠顶翻到下方，夹在编辑区内边 8px。无锚点时退回距顶 44px 居中。按下即触发（避免行内编辑先失焦）。

**结果预览卡**：最大宽 560、最小 200；标题 10.5/600 muted，正文 12.5 可选中；过长 internally 滚动，**替换 / 关闭**永远留在卡内。距宿主边至少 8px。

### 6.14 Logo

22px（标题栏）/ 256px（任务栏）同一套矢量：强调色圆角方块，里面是「太阳 + 山」小图，下面两道 caption 线。前景一律 `onaccent`。`packaging/icon.ico` 可整文件替换。Windows 设 `AppUserModelID`，任务栏图标才不跟 Python 混。

## 7. 各栏视觉规格

### 7.1 左侧图标轨 + 预览信息栏

- 轨宽 **44**，底 `panel`，右沿 1px `bd`；图标钮 32、圆角 8
- 顶：强调色 Logo 22（点开：使用说明 / 关于 / 退出）
- 中段可滚：打开、保存、全部保存、导出、撤销、重做、修改工具
- 底段钉住：主题、设置
- 预览信息栏高 **46**：文件名、格式胶囊、尺寸 / 大小 / 修改于、未保存、对比、上一张/下一张、窗控 ─ □ ×（各宽 44，关闭 hover 系统红）
- 轨空白与信息栏空白可拖窗；双击信息栏最大化；按下后超过拖拽阈值才进系统拖动（避免吞双击）

### 7.2 左栏

- 栏头：17px 文件夹标、数据集名、等宽路径省略、两个 26px 工具按钮
- 搜索高 **29**
- 视图分段钮 27×22
- 网格间隙 10；列表行间隙 6、行高 62
- 分组头高 27；箭头开合 240ms
- **当前项**：强调描边 + 软光晕（网格 3px glow）
- **未保存**：`warn` 实心圆（列表 6px / 网格 8px，外一圈浅环）
- 网格底 36px 暗角（墨黑 62% 透明）+ 白字文件名 10.5 + 段数 9.5
- 列表：34×44 缩略图、文件名 11、预览最多 4 段

### 7.3 预览顶栏 / 画布

- 顶栏高 **46**
- 导航钮 28；动作钮高 29
- 图圆角 10，区垫 22
- 多图：间隙 14，格圆角 12，边 2 + 外发光 3
- 缩放条浮在右下：± 26px，「适应」或 `n%`
- 切图：绘制 alpha 从 0.55 → 1，**170ms**（自己画，不用图形效果）
- 缩放 10%–800%，每格 20%；双击「适应 ↔ 100%」
- 「适应」的有效下限可以低于 10%，保证大图也能整张看见

### 7.4 编辑区

- 页签：12.5/600，水平垫 15，半径 8
- 工作区按钮：12/600，水平垫 11，半径 7

## 8. 交互状态（统一语言）

| 状态 | 怎么表现 |
|---|---|
| 默认 | `surface` / 透明 + `bd` 或无边 |

## 9. 动效

总开关 `nlapt_gui.anim.ANIMATIONS_ENABLED`。测试里关掉。关时跳终态、返回 `None`。

| 场景 | 做法 | 时长 | 曲线 |
|---|---|---|---|
| 主窗首次出现 | `windowOpacity` 0→1 | 240ms | 默认 |
| 主窗关闭 | `windowOpacity` 1→0 再关 | 140ms | 默认 |
| 最大化 / 还原 | 先降到 0.55 再回到 1，盖住几何跳变 | 90 + 130ms | 默认 |
| 子窗出现 | 居中 + `windowOpacity` 0→1 | 160ms | OutCubic |
| 子窗关闭 | `windowOpacity` 1→0 | 120ms | OutCubic |
| 主题切换 | 主窗短暂透明过渡（ThemeManager） | — | — |
| 切图 | 自绘 alpha 0.55→1 | 170ms | — |
| 文件夹箭头 / 组 | 旋转 + 高度 | 240ms | — |
| 折叠卡片箭头 | 0° ↔ −90° | （展开本身瞬间） | — |
| `anim.fade_in/out` | 小控件透明度（非顶层） | 180ms | InOutQuad |
| `anim.pop_in` | 透明度 + 几何从中心缩 6% 弹出 | 260ms | OutBack overshoot 1.1 |
| Toast | 出现后 2600ms 消失 | — | — |

**硬规则**

- 顶层窗、会随窗口缩放的预览/面板：**只用 `windowOpacity` 或自己画 alpha**。
- `QGraphicsOpacityEffect` 只允许在短命、不随窗缩放的小件上（例如正在拖的胶囊半透明）。`anim.py` 的 effect 不得挂到 MainWindow / Preview。
- 测试 grep 活控件上的 `QGraphicsOpacityEffect`。
- QSS 里带 `;` 的 `url()` 必须加引号。

## 11. 文案与空态

- 界面中文；代码英文。
- 用户字符串模块顶常量（`TEXT_` / `LABEL_` / `TIP_` / `TOAST_` / `MENU_`）。
- 弱提示用 `muted`（`text3`），次要用 `secondary`（`text2`）。
- 空列表：「没有匹配的文件」
- 空胶囊：「暂无内容,点击「+ 标签」添加」
- 未配 API：引导句 +「打开设置」链接（强调色、600），不是空白报错
- 本地推理未选量化档：「在左侧展开一个系列…」
- 确认框按钮固定 **确定 / 取消**

标点按现有文案：中文逗号、不用行尾句号也可以（很多按钮/toast 本来就是短语）。

## 12. 会记住的界面状态

|---|---|

## 13. 前端分层（和视觉的关系）

```
widgets/*          只拼控件、发信号；不读盘、不碰 nlapt.*
       ↓
controller.py      UI ↔ 核心唯一桥（Qt 信号）
translate/vision/local_bridge    异步，结果排队回主线程
       ↓
theme/tokens.py    唯一色表
theme/qss.py       唯一全局样式表
theme/manager.py   apply() → QSS + palette + 持久化 + theme_changed
```

例外（合同允许）：`settings_dialog.py`、`local_tab.py` 可直接读写 `config.json`；`thumbnails.py` 可写缩略图缓存。

控件之间禁止平级互调，只通过 controller 或父→子组合。

线程：重活 `QThreadPool` + `run_async`；回 UI 只用排队信号；接收方可能已拆时用 `shiboken6.isValid`。

## 14. 设计检查清单（改界面时）

1. 新颜色是否来自令牌 / `mix` / `accent_soft`？控件文件有没有新的 `#`？
2. 圆角是否落在 6 / 7 / 8 / 11 / 12？
3. 主操作是 `accent`，次操作 `outline`，破坏性是确认框或 `danger-ghost`？
4. 选中态是 soft + accent 边，而不是另造一套色？
5. 顶层或会缩放的活控件有没有挂 `QGraphicsOpacityEffect`？
6. 新动画是否走 `anim`，关掉时终态是否正确？
7. 中文文案是否模块顶常量？
8. QSS `url()` 含 `;` 是否加了引号？
9. 深浅五套 + 自定义强调是否都看得清（尤其 onaccent、弱文）？
10. 空态 / 未配置 / 忙碌 / 失败是否都有对应视觉，而不是空白？
