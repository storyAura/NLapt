# NLapt 更新说明

产品版本 **0.2.2**。面向使用者：界面上能看见的变化。

---

## 0.2.2

### 更新

- **CHA标注多角色卡**：一次最多锁定 8 张角色卡（多个角色，或同一角色多套服装）。向导按角色卡分页填写角色名 / 作品名、各选参考图，每张卡仍生成三个方案；每张图一次调用内先判定属于哪几张卡，再逐卡核对服装，写入「匹配的人物卡（可多张）+ 空行 + 画面段」。判定都不属于的图会跳过不写，原文不动。
- **角色卡汇总弹窗**：整批结束后弹出本次锁定的角色卡，可单卡复制或复制全部，并列出未归类与失败的图片。

- **CHA标注向导改为横构图**：宽屏左右分栏——左侧角色卡标签、引擎与参考图多行网格，右侧整块大图预览；候选人物卡一行三张并排，确认页左卡右画面段。
- **未归类图片可逐张移出**：汇总弹窗里每张「未归类」图带缩略图与「移出」勾选，确认后连同同名 txt 移到 `.backups/duplicates/`，可用「撤销上次图像操作」恢复；双击行可在主窗口查看该图。
- **CHA 角色识别（可选）**：设置 ▸ CHA标注 可填写全局 Hugging Face Token（存在文档目录），下载受限模型 CL Tagger v2.01a 与 Danbooru 角色对照表。向导第一页「识别角色」从参考图推出角色名 / 作品名，父子与同级变体列在菜单里供选择。
- **CHA 提示词可分别自定义**：设置 ▸ CHA标注 ▸ 编辑提示词 左右两栏分别改「人物卡」和「画面段」提示词，可恢复默认。与内置文案相同则仍走默认，之后内置更新会自动跟上。

### 修复

- **CHA标注服装状态判定更严格**：只有官方服装里每件衣物、配饰都按卡上写法穿在身上才原文写入；帽子拿在手里、外套脱下、衣襟敞开、配饰缺失等都会改写服装段并写明实际状态。
- **CHA标注参考图可从整个训练集选取**：以前只列出本次要写入的那批图（右键某文件夹启动时就只有该文件夹），现在缩略图条默认列出全部图片，上方可按文件夹筛选；切换角色卡时会自动跳到该卡参考图所在的文件夹。要写入哪些图仍由启动时的范围决定。
- **勾选框 / 下拉箭头 / 表头跟随主题**：已选状态显示勾号，半选有横杠；下拉箭头用主题色 SVG（Qt 不支持 data URI，改为写入用户数据目录）；本地推理表头不再黑底；切换主题后标签页、单选和数字框不再残留旧配色。
- **CHA 人物卡改为整句、帽子归服装**：不再要求「角色名, 发色, 长度」这种标签碎片；帽子、发饰、头巾只写在服装段，避免混进外貌开头。

## 0.2.1

### 更新

- **多 API 与模型池**：同时保存多个 API 档案，逐个模型开关；从池里分别选当前文本模型（翻译 / 改写）和当前视觉模型（推标），可来自不同供应商。旧配置自动升到 `api.json` v2。
- **CHA标注**：三个方案与整批画面可按供应商从模型池选模型；人物卡按发色 / 发型 / 眼睛 / 体表 / 服装书写，画面段同时核对服装。
- **多对比推标**：同一批图同时交给多个模型，并排核对、可编辑后再写入已选结果。
- **工具弹层**：轨上「工具」按处理 / 标注 / 预处理分组，顶部可切换当前模型。
- **图像工具**：替换透明底、查找雷同图片；批量范围增加「文件夹」；可撤销上次图像操作。
- **本地推理**：目录里的模型可一键设为当前文本 / 视觉模型。

### 修复

- Windows 启动 / 打包脚本不再漏装 `httpx` 与 Florence 依赖。
- 预览顶栏文字不再挡住拖窗；长文件名中间省略。
- 本机 Hy-MT2 翻译多段原文时按段翻完再拼回。
- 删除标注、批量覆盖推标、移出雷同、删除翻译模型时，回车默认「取消」；替换透明底 / 查找雷同 / 色彩设置补上取消或关闭，取消色彩会还原打开时的主题；同文案轻提示不再叠层，同时最多显示 4 条。

## 0.2.0

### 更新

- **本地推理**：设置新增本页。内置 GGUF 目录（体积、热度、五级「能否运行」），应用内下载、断点续传、SHA256 校验。首次使用自动下载官方 llama.cpp。**设为当前模型** 后翻译 / 重译 / 批量推标走本机。Florence-2 走指令模式，可挂 LoRA（不能做 CHA标注）。JoyCaption / ToriiGate 带官方提示词预设。推理拉起的服务空闲 30 秒卸载。
- **CHA标注**（组合分层推标）：先锁定人物卡，再为每张图只写姿态与场景。左栏右键：这张 / 已选 / 此文件夹 / 全部（含未标注）。设置可同步主 LLM 或单独接口，三个方案与整批画面可各选模型。
- **批量推标**：右键对文件夹 / 已选 / 全部做 LLM 或本地推标，带进度、可取消。
- **翻译通道**：DeepLX（社区或自建）、本机 Hy-MT2（快速 / 均衡 / 高质量）、自定义 OpenAI 兼容。可设**备选顺序**，首选失败后继续。预览区底部可看整篇译文对照。
- **设置**：五页（翻译服务、LLM、提示词、本地推理、CHA标注）。提示词新增内置只读方案「结构化视觉编译」「客观视觉报告」。
- **接口配置**：类型 / 地址 / 密钥 / 模型名统一写在 **文档\NLapt\api.json**。第一次启动会把旧文件迁过去。
- **数据位置**：批量快照与崩溃会话改到 `%APPDATA%\NLapt\datasets\`，数据集目录只留图 + txt。
- **导出**：把当前数据集的图片和已有 txt 打成 zip。
- 发布包瘦身；控制台日志仅调试模式开启。

### 修复

- 胶囊 / 分句拖拽排序后不再重叠、消失或卡住半透明；松手后再写入顺序。
- 窗口最大化 / 还原过渡正常。
- 社区 DeepLX 忙时（HTTP 429 / 418）会退避重试，失败只提示「过于频繁」，不再出现 teapot / 原始 JSON。
- 本机 Hy-MT2 翻译不再一直转圈不出结果。
- CHA标注写入中文对照后，窗口不再被顶出屏幕。
- 被安全策略拦截的拒绝话术不会写进数据集。
- 翻译、模型下载、缩略图各走自己的后台，互不堵住。

### 移除

- 底部常驻状态栏（保存状态、快捷键提示、时钟）。改走 Toast、列表黄点、推标进度窗。
- 数据集目录里的 `.backups/`、`.nlapt/`（已迁到 AppData；打开旧数据集会尽量搬走）。
- 密钥不再写进 `%APPDATA%\NLapt\config.json`，也不再拆成 `translate_api.json` / `cha_api.json`。
